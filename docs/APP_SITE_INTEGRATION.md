## 4. 디자인 원칙 — 한 브랜드, 두 시간대

- 사이트는 낮(밝은 웜톤), 앱은 밤(어두운 화면)으로 두고 **지금 억지로 하나로 맞추지 않습니다.** 대표님이 디자인을 계속 바꿀 예정이므로, 같이 쓰는 것은 로고·연락처·사업자 정보만으로 제한합니다.
- 테마가 바뀌는 링크에는 "포온 홈페이지 ↗", "포온 앱에서 열려요"를 작게 붙여 전환을 예고합니다.
- 2단계: 추모 화면(추억상자, 부고장)의 강조색을 네온 라임에서 따뜻한 촛불 톤으로 바꿉니다. 라임은 멍BTI·AI 같은 "살아 있는 아이" 쪽에만 씁니다.
- 3단계:
  - 공통 의미 토큰(`.site` / `.app`)을 만들고, 로고 컴포넌트를 공용으로 씁니다.
  - 앱에도 Pretendard를 적용하고, 앱 이모지 아이콘을 사이트와 같은 아이콘으로 바꿉니다.
- 브랜드 표기:
  - 한글 "포온", 영문 "po-on", "포온 앱", "포온 AI 도우미"로 씁니다.
  - foon은 도메인에서만 씁니다.
  - "Po-ON by 21gram", "MAPS", "펫터디"는 화면에서 지웁니다(법인명 확정 시 법정 표기만 예외).
