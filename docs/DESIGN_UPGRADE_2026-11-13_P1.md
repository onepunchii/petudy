## 1. 장례식장 저장·최근 본 곳·비교
- 저장은 로그인 없이 이 기기(localStorage)에만 둡니다(`src/lib/site/home-shelf.ts`).
  - 저장은 최대 3곳, 최근 본 곳은 5곳입니다. 서버로 보내지 않습니다.
  - 다른 탭과도 맞춰지고, 서버 렌더에서는 빈 목록이라 하이드레이션이 어긋나지 않습니다.
- 장례식장 상세 히어로에 '저장' 버튼(aria-pressed)이 있습니다. 3곳이 차면 "비교는 3곳까지예요"라고 안내합니다. 상세를 열면 최근 본 곳에 들어갑니다.
- `/funeral-homes/compare`(검색 제외 noindex): 저장한 곳을 가격·운영 시간·서비스 11항목·전화로 나란히 보는 표입니다.
  - 휴대폰에서는 옆으로 밀어 보고, 항목 칸은 고정됩니다.
  - '빼기'로 저장을 지울 수 있고, 아래에 최근 본 곳이 나옵니다.
- 장례식장 목록(전국·시도)에는 저장했거나 본 곳이 있을 때만 "저장한 장례식장 N곳 비교하기" 입구가 보입니다.

## 2. 장례식장 목록 필터 (시·도 화면)
- 조건은 24시간 접수, 화장 참관, 대형견 장례, 공개 가격 20만 원 이하부터이며, 모두 맞는 곳만 남깁니다(`FilteredHomeGroups.tsx`).
- 조건은 '업체 홈페이지에 안내가 있는 곳'만 뜻합니다. 화면에 "안내가 없다고 하지 않는다는 뜻은 아니에요"를 적었습니다.
- 서버 HTML 에는 걸러지지 않은 전체 목록이 그대로 있습니다(검색 노출 유지). 남은 곳이 없는 시·군·구 묶음은 숨기고, 결과 수는 aria-live 로 알립니다.
- 목록 한 줄을 데이터 전용 부품 `HomeRow`(서버에서 만든 값만 받음)로 나눴습니다. 브라우저가 업체 JSON 전체를 받지 않게 하려는 것입니다. 캡션 글자를 12~12.5px 에서 13px 로 올렸습니다.

## 3. 업체 사장님 입구
- 장례식장 상세 맨 아래에 "이 장례식장 사장님이세요?"(목차 '업체 사장님')를 두었습니다(`detail/OwnerSection.tsx`).
  - 접힌 버튼을 펼치면 제휴 문의 폼이 나오고, 업체명·소재지가 미리 채워집니다.
  - 접수에는 이 페이지 주소가 함께 남습니다.
- `LeadForm` 에 `defaults` 를 추가했고, 입력 글자를 16px 로 올렸습니다(아이폰 자동 확대 방지).
- 상담 접수가 실제로 도착하려면 배포 전 체크리스트의 `LEAD_WEBHOOK_URL` 또는 DB 연결이 먼저 필요합니다.
